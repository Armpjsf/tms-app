# DRouteMind — สคริปต์เสียงบรรยาย (Voice-Over Script)

**แบรนด์:** DRouteMind (by DD Transport) | **สีแบรนด์:** #17265f
**น้ำเสียง:** ผู้ชาย/ผู้หญิงเสียงทุ้ม มืออาชีพ มั่นใจ อบอุ่นเล็กน้อย | พูดชัด จังหวะกลาง เร่งขึ้นช่วงกลาง
**หมายเหตุ:** เว้นวรรค (/) = จังหวะหายใจสั้น | ( ) = คำแนะนำอารมณ์

## เวอร์ชันเต็ม ~95 วินาที

**[ฉาก 1 — ปัญหา] (โทนตั้งคำถาม เนิบ)**
ทุกวันในธุรกิจขนส่ง / เต็มไปด้วยคำถามที่ยังไม่มีคำตอบ

**[ฉาก 2 — เปิดตัว] (สว่างขึ้น มั่นใจ)**
DRouteMind / รวมทุกการเดินรถของคุณ / ไว้ในหน้าจอเดียว / เห็นทุกงาน ทุกคัน แบบเรียลไทม์

**[ฉาก 3 — วางแผน] (กระชับ)**
สร้างงาน จับคู่รถกับคนขับ / แล้วจ่ายงานถึงมือคนขับทันที / จบในไม่กี่คลิก

**[ฉาก 4 — ePOD] (เน้นหนักแน่น เป็นพระเอก)**
ถึงปลายทาง / ลูกค้าเซ็นรับบนจอ ถ่ายรูปเป็นหลักฐาน / รู้ทันทีว่าใครรับ ส่งเมื่อไหร่ / ไม่มีใบส่งของหายอีกต่อไป

**[ฉาก 5 — AI] (ทันสมัย น่าตื่นเต้น)**
และนี่คือสิ่งที่ระบบขนส่งทั่วไปไม่มี / ผู้ช่วย AI ที่คุยเป็นภาษาไทย / ถามข้อมูลได้ / สั่งให้สร้างงานให้ได้ในประโยคเดียว

**[ฉาก 6 — ลูกค้า+LINE] (อบอุ่น ผ่อนคลาย)**
ลูกค้าเปิดลิงก์ดูสถานะเองได้ทุกที่ / พร้อมแจ้งเตือนผ่าน LINE ที่คนไทยใช้จริง / ลดสายโทรเข้า ทีมงานมีเวลาทำงานจริง

**[ฉาก 7 — All-in-one] (พลังขึ้นสูงสุด)**
ออกใบแจ้งหนี้ คิดค่าเที่ยว ดูแลน้ำมันและซ่อมบำรุง / ไปจนถึงปุ่มฉุกเฉิน SOS / ทุกอย่างอยู่ในระบบเดียว / วางบิลเร็วขึ้น เงินเข้าเร็วขึ้น

**[ฉาก 8 — ปิด] (หนักแน่น เชิญชวน)**
DRouteMind / เห็นทุกคัน ยืนยันทุกงาน ควบคุมได้ทุกเที่ยว / ติดต่อเราวันนี้
